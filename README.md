# ITIL5 Lernapp

Multiple Choice Webapp zum Lernen fuer die ITIL Foundation Version 5 Zertifizierung.

## Funktionen

- Lernmodus mit direktem Feedback
- Pruefungsmodus mit zufaelligen Fragen
- Score- und Fortschrittsanzeige
- Bestehenslogik: 26 von 40 Punkten

## Lokal starten

```bash
npm install
npm run dev
```

Dann oeffnen: http://localhost:5173

## Build

```bash
npm run build
```

Hinweis: Die Fragen sind uebungsorientierte Lernfragen auf Basis der bereitgestellten Sample-Paper-Themen und keine vollstaendige 1:1-Kopie der PDFs.
